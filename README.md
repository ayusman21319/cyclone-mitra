# Cyclone Mitra

**Powered by Nexora Team**  
A multilingual cyclone preparedness awareness website for the All Odisha Hackathon.

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Create and activate a virtual environment (recommended).
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the app:

   ```bash
   python app.py
   ```

6. Open http://127.0.0.1:5000

## Important

- The current version is the first frontend/backend scaffold.
- The AI assistant and live radar integrations are not active yet. Do not present sample content as live emergency data.
- For real emergencies in India, call **112**. Follow official IMD, OSDMA and government alerts.
- Never put API keys or passwords in GitHub. Store secrets as environment variables when integrations are added.
